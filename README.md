# Organizador Pessoal de Busca de Emprego

Aplicação local, pessoal e de usuário único para organizar a busca de vagas de desenvolvimento: cadastro e triagem de oportunidades, preparação assistida de candidaturas e acompanhamento do processo seletivo.

## Stack planejado

- Next.js e TypeScript
- SQLite com Prisma
- Worker Node.js para tarefas em segundo plano
- Docker Compose com persistência local
- Testes unitários, de integração e de interface

O MVP deve funcionar sem integração de IA ou e-mail, começando por um fluxo completo de entrada manual de vagas.

## Status

Repositório inicial criado. A implementação será feita em incrementos funcionais e verificáveis conforme o briefing do projeto.
